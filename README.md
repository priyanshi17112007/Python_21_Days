## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/priyanshi17112007/Python_21_Days.git
```

**2. Navigate to the project folder**

```bash
cd Python_21_Days
```

**3. Run a Python script**

```bash
python python_day1.py
```

Replace `python_day1.py` with any script you want to explore.
